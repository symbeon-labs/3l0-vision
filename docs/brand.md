# Brand

## Name

**3L0 Vision**

Verbal reading: **Elo Vision**.

The written identity is intentionally different from the spoken name.

## Meaning

3L0 is not a literal abbreviation that needs to be decoded.

It is a visual identity.

The central visual element is the open/broken circle:
- connection
- passage
- convergence
- resolution
- completion

## Symbol

The existing 3L0/ORC visual language is based on:
- scan frame
- convergence ring
- confirmation mark
- completion arc

The symbol should function as a state language, not decoration.

## State language

Cyan — capture / observation
Green — resolved / valid progression
Amber — attention / intermediate state
Red — conflict / unresolved

Near-black — environment

## Typography

Use a clean sans-serif for operator interfaces and a compact technical type treatment for identifiers and diagnostics.

Do not introduce decorative typography merely for branding.

## Voice

Direct.
Operational.
Calm.
Precise.

Avoid:
- AI hype
- claims of certainty without evidence
- excessive technical language in operator interfaces
- childish gamification

## Product statement

**Tornar o mundo físico computável.**
